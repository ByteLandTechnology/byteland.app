ghidra-bridge

Network access to a running Ghidra program, over WebSocket JSON-RPC 2.0 and MCP.

GitHub
$./gradlew buildGhidraScript
Java

Two transports

WebSocket JSON-RPC 2.0 and MCP Streamable HTTP.

53 typed methods

One catalog, from interface.get to batch.execute.

Atomic batches

Batch operations roll back on error.

Secure by default

Loopback binding and bearer tokens.

How it works

  1. 1

    Build

    ./gradlew buildGhidraScript produces the scripts and a zero-dependency JAR.

  2. 2

    Start

    Run Bridge.java or GhidraMcp.java in the GUI or as a headless post-script.

  3. 3

    Connect

    Point a WebSocket client or MCP agent at the bridge.
