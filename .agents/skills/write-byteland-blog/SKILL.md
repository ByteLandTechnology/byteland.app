# Write a ByteLand technical article

Produce one useful, evidence-led English article about AI, LLMs, agents, AI coding or
recent GitHub developments. Read existing posts, repository instructions and current
article components before choosing a topic or changing frontmatter. Avoid duplication.

Read [research and writing](references/research-and-writing.md) for topic selection,
experiments, evidence, ASD-STE100 Issue 9 review and reproducibility.
Read [visual and video requirements](references/visual-and-video.md) when preparing
illustrations, animation, speech, sound or captions.
Read [review and publishing](references/review-and-publishing.md) before previewing or publishing.

Deliver a reviewable article, necessary media, direct sources, runnable experiment
materials, terminology list and explicit validation limitations. Work in an isolated
cloud checkout. Do not use personal computers, Codex quota, paid Actions or paid cloud
rendering. Use an already-authorized Pi/BigModel setup only when available; never copy
credentials into prompts or source. Inspect code and scripts before execution.

Keep drafts outside production `public/` until the exact version is approved.
An approved preview is not permission to publish; silence is not approval. A substantive
change after approval needs another review. Publish only when explicit authorization
covers that article version and destination. This skill does not itself grant access,
publication, recurring automation, or third-party data-sharing permission.
